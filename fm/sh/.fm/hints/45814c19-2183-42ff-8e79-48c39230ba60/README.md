# "DC 계수"의 DC는 어디서 왔는가

> **Q.** "DC 계수"에서 DC라는 용어는 어디서 왔는가?
> **A.** 신호처리 용어 **direct current(직류)**, 즉 **주파수 0 성분**에서 왔다. SH에서는 $\ell=0$ 항의 계수 $c_0^0$을 가리킨다.

한 줄로 요약하면 **"DC = 시간(또는 방향)에 따라 변하지 않는 평균 성분"** 이고, 이 뜻이 전기공학 → 푸리에 해석 → 이미지 압축 → 구면 조화 함수(SH) → 3DGS까지 그대로 이어져 내려왔다. 아래에서 그 경로를 순서대로 따라간다.

---

## 1. 출발점: 전기공학의 DC / AC

| 용어 | 뜻 | 파형 |
|---|---|---|
| **DC** (Direct Current, 직류) | 전류의 방향·크기가 **시간에 따라 변하지 않음** | 수평선 (상수) |
| **AC** (Alternating Current, 교류) | 전류의 방향이 **주기적으로 바뀜** | 사인파 등 진동 |

배터리는 DC, 벽 콘센트(60 Hz)는 AC다. 여기서 핵심은 "DC = 상수", "AC = 진동" 이라는 대비다.

### 임의 신호 = DC 성분 + AC 성분

실제 회로의 전압 $v(t)$는 순수 DC도 순수 AC도 아닌 경우가 많다. 전기공학에서는 이를 관습적으로 두 부분으로 나눈다.

$$
v(t) = \underbrace{\overline{v}}_{\text{DC 성분(평균)}} + \underbrace{\big(v(t) - \overline{v}\big)}_{\text{AC 성분(평균 0인 변동)}}
$$

- **DC 성분** = 신호의 **시간 평균** (오실로스코프의 "DC offset", 증폭기의 "바이어스" 등)
- **AC 성분** = 평균을 뺀 나머지. 정의상 평균이 0이다.

예컨대 오디오 앰프 설계에서 "DC 커플링 커패시터"는 평균(DC)을 차단하고 진동(AC)만 통과시키는 부품이다. 이 "평균 vs. 변동" 분해 습관이 다음 단계의 어휘를 결정했다.

---

## 2. 푸리에 해석에서 "0 Hz 성분 = DC"로 굳어지다

주기 $T$인 신호를 푸리에 급수로 전개하면

$$
v(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty}\Big(a_n \cos\tfrac{2\pi n t}{T} + b_n \sin\tfrac{2\pi n t}{T}\Big),
\qquad
\frac{a_0}{2} = \frac{1}{T}\int_0^T v(t)\,dt = \overline{v}
$$

- $n=0$ 항 $a_0/2$는 **주파수 0 Hz**의 성분이며, 그 값은 정확히 **신호의 평균**이다.
- $n\ge 1$ 항은 모두 한 주기 동안 적분하면 0 → 평균이 0인 진동 성분.

즉 1절의 "DC 성분 = 평균, AC 성분 = 변동"이 주파수 영역에서는 "**0 Hz 항 = DC, 나머지 = AC(고조파)**"에 정확히 대응한다. 전기공학자들이 푸리에 해석을 회로 분석에 도입하면서 0 Hz 항을 그냥 **"DC 항(DC term)"**, 그 계수를 **"DC 계수"** 라고 부르게 되었고, 이 관용어는 신호가 전류가 아닌 경우(음성, 이미지, 구면 함수 …)에도 그대로 살아남았다.

### 같은 용어가 쓰이는 다른 분야

| 분야 | 수식 | "DC"가 가리키는 것 |
|---|---|---|
| 푸리에 급수 | $a_0/2$ | 한 주기 평균 |
| 이산 푸리에 변환(DFT) | $X[0] = \sum_{n=0}^{N-1} x[n]$ | 샘플 합 (= 평균 × $N$). FFT 결과의 첫 번째 bin을 "DC bin"이라 부른다 |
| JPEG (8×8 DCT) | $F(0,0)$ — 블록 좌상단 계수 | 블록 64픽셀의 평균 밝기(× 8). 나머지 63개는 "AC 계수"라 부르며 별도의 허프만 테이블(DC/AC 테이블)로 부호화한다 |
| 오디오/DSP | "DC offset 제거", "DC blocker" | 평균값(0 Hz) 제거 필터 |
| 구면 조화 함수(SH) | $c_0^0$ ($\ell=0$) | 구면 위 함수의 **구면 평균** ← 이 카드의 주제 |

JPEG 표준 문서와 대부분의 DSP 교과서가 이 어휘를 명시적으로 쓰기 때문에, 그래픽스 분야(SH 조명, PRT, 3DGS)에서도 "DC 계수 / 고차(AC) 계수"라는 표현이 자연스럽게 통용된다.

## 3. SH에서 $\ell=0$ 항이 정확히 "DC"인 이유

구면 위 함수 $f(\mathbf d)$ ($\|\mathbf d\|=1$)의 SH 전개는 구면 위의 "푸리에 급수"다.

$$
f(\mathbf d) \approx \sum_{\ell=0}^{L}\sum_{m=-\ell}^{\ell} c_\ell^m\,Y_\ell^m(\mathbf d)
$$

- $\ell$(차수, band)이 1D 푸리에의 주파수 $n$에 대응한다. $\ell$이 클수록 구면 위에서 더 잘게 진동한다.
- $\ell$차 SH는 $x,y,z$의 $\ell$차 동차 다항식을 단위구에 제한한 것. **0차는 상수**, 1차는 선형($x,y,z$ 자체), 2차는 이차식 …

### 3.1 $Y_0^0$은 방향과 무관한 상수

$$
Y_0^0 = \frac{1}{2\sqrt{\pi}} \approx 0.2821 \;(=\texttt{C0})
$$

"주파수 0" = "방향에 따라 변하지 않음" = 상수. 이것이 $\ell=0$ 항을 DC라 부르는 첫 번째 이유다.

### 3.2 DC 항만으로 복원하면 구면 평균이 나온다

정규직교성 덕분에 계수는 내적으로 구해진다. $Y_0^0$이 상수이므로

$$
c_0^0 = \int_{S^2} f(\mathbf d)\,Y_0^0\,d\Omega = \frac{1}{2\sqrt\pi}\int_{S^2} f\,d\Omega
\quad\Longrightarrow\quad
c_0^0\,Y_0^0 = \frac{1}{4\pi}\int_{S^2} f\,d\Omega = \overline{f}
$$

($4\pi$는 단위구 표면적.) 즉 **$c_0^0 Y_0^0$은 $f$의 구면 평균**이다. 이것이 1D 푸리에의 $a_0/2 = \overline v$와 완전히 같은 구조다.

### 3.3 나머지 항($\ell\ge1$)은 모두 "AC" — 구면 평균이 0

각 $Y_\ell^m$ ($\ell\ge1$)은 $Y_0^0$과 직교하므로

$$
\int_{S^2} Y_\ell^m\,d\Omega = 2\sqrt\pi\int_{S^2} Y_\ell^m\,Y_0^0\,d\Omega = 0
$$

따라서 고차 항들은 평균에 아무 기여도 하지 않고 **평균 주위의 방향별 변동**만 담는다. 1절의 "DC(평균) + AC(평균 0인 변동)" 분해가 구면에서도 그대로 성립한다.

노트북(`sh_walkthrough.py` 3절)에서는 환경맵 $f$로 이를 수치 확인한다.

```python
mean_f = (f * w[..., None]).sum(dim=(0, 1)) / w.sum()   # 구면 평균 (RGB)
print("f의 구면 평균         :", mean_f)
print("DC 항만으로 복원 c₀·Y₀:", coeffs_env[0] * C0)      # 두 값이 일치
print("고차 항(ℓ≥1)만의 구면 평균:", ...)                  # ← 0
```

## 4. 3DGS / gsplat에서의 DC: `sh0`와 `shN`, `f_dc_*`와 `f_rest_*`

3DGS는 Gaussian마다 색을 SH 계수 16개(3차, $(3+1)^2=16$) × RGB 3채널로 저장하고, 시점 방향 $\mathbf d$에서

$$
\mathbf c(\mathbf d) = \max\!\Big(0,\ \sum_{k=0}^{15}\mathbf c_k\,Y_k(\mathbf d) + 0.5\Big)
$$

로 색을 평가한다. 여기서 $k=0$ 계수 $\mathbf c_0$이 DC이며 그 뜻은 3절 그대로 — **어느 방향에서 봐도 공통인 기본색(구면 평균)** 이다. 고차 15개는 하이라이트·프레넬 같은 시점 의존 변동(= AC)을 담는다.

### 4.1 파라미터를 DC / 고차로 분리: `sh0`, `shN`

gsplat의 `examples/simple_trainer.py`는 계수 텐서 `[N,16,3]`을 두 파라미터로 쪼갠다.

```python
params.append(("sh0", torch.nn.Parameter(colors[:, :1, :]), sh0_lr))   # [N, 1, 3]  DC
params.append(("shN", torch.nn.Parameter(colors[:, 1:, :]), shN_lr))   # [N,15, 3]  고차
```

```python
sh0_lr: float = 2.5e-3
shN_lr: float = 2.5e-3 / 20      # 고차는 1/20 학습률
```

- 렌더링 시에는 `torch.cat([splats["sh0"], splats["shN"]], 1)`로 다시 `[N,16,3]`을 만든다.
- **학습률을 다르게 두는 이유**: 기본색(DC)은 SfM 포인트 색으로 이미 좋은 초기값이 있고 loss에 직접적으로 크게 영향하므로 빨리 맞추고, 시점 의존성(AC)은 관측 수가 적으면 과적합하기 쉬우므로 천천히 배우게 한다. 원본 3DGS 구현(`feature_dc` / `feature_rest`, 학습률 0.0025 vs 0.0025/20)의 관행을 그대로 따른 것이다.
- 여기에 `sh_degree_interval`(1000 스텝마다 사용 차수 +1)까지 더해, 처음엔 DC만, 점차 고차를 켜는 "저주파부터 학습" 전략을 쓴다.

### 4.2 초기화 `sh0 = (rgb − 0.5) / C0` 도 DC의 뜻에서 나온다

학습 시작 시 `shN = 0`이면 색은 $c_0 Y_0^0 + 0.5$로 모든 방향에서 동일하다. 이것이 SfM 포인트 색 `rgb`와 같아지려면

$$
c_0 = \frac{\mathbf{rgb} - 0.5}{Y_0^0} = \frac{\mathbf{rgb}-0.5}{C_0}
$$

`+0.5` 오프셋은 계수가 전부 0일 때 색이 검정이 아니라 중간 회색이 되게 하여, 계수가 양·음 대칭으로 움직일 수 있게 하는 장치다. 반대 방향 변환 `sh2rgb`는 $c_0 C_0 + 0.5$.

### 4.3 PLY 파일 필드명: `f_dc_0..2` / `f_rest_*`

3DGS 원본 뷰어 호환 PLY 포맷은 이 분리를 필드 이름에 그대로 박아 두었다.

| PLY property | 내용 | shape |
|---|---|---|
| `f_dc_0`, `f_dc_1`, `f_dc_2` | **DC 계수** $c_0$의 R, G, B | Gaussian당 3개 |
| `f_rest_0` … `f_rest_44` | 나머지($\ell=1..3$) 15개 × 3채널 | Gaussian당 45개 (채널-major 순서) |

gsplat의 `gsplat/utils.py` `save_ply`가 이 이름을 쓴다.

```python
for i, data in enumerate([sh0, shN]):
    prefix = "f_dc" if i == 0 else "f_rest"
    ...
# 색만 있는 경우(SH 미사용)에도 rgb를 DC 계수로 변환해 f_dc_*에 저장
f_dc = (color[i, j] - 0.5) / 0.2820947917738781
```

`gsplat/exporter.py`의 PLY 로더도 "the DC term (k=0) lives in `f_dc_0..f_dc_2` separately"라고 명시하며 `f_dc_*`와 `f_rest_*`를 따로 읽어 `[N,16,3]`으로 재조립한다. `f_dc`의 "dc"가 바로 이 카드의 DC이고, `f_rest`는 "AC"에 해당하는 나머지(rest) 항이다. 즉 파일 포맷·파라미터 이름·학습률 스케줄·초기화 공식이 전부 "$\ell=0$ = 방향 무관 평균 = DC"라는 하나의 관념에서 파생된다.

## 5. 정리

```
전기공학   DC(직류: 상수) vs AC(교류: 진동)
   │        임의 신호 = 평균(DC) + 평균 0인 변동(AC)
   ▼
푸리에     0 Hz 항 a₀/2 = 평균  →  "DC 항 / DC 계수"      (DFT: X[0], JPEG DCT: F(0,0))
   │
   ▼
SH         ℓ=0 항 c₀⁰·Y₀⁰ = 구면 평균, ℓ≥1 항은 구면 평균 0
   │
   ▼
3DGS       sh0(DC, 기본색, lr 2.5e-3) + shN(고차, 시점 의존, lr /20)
gsplat     초기화 (rgb−0.5)/C0,  PLY의 f_dc_0..2 / f_rest_0..44
```

- **DC라는 이름의 근원**: 직류(direct current) = 시간에 따라 변하지 않는 성분 → 주파수 0.
- **왜 SH의 $\ell=0$이 DC인가**: $Y_0^0$이 상수이고, $c_0^0Y_0^0$이 정확히 구면 평균이며, 나머지 항은 평균이 0이기 때문.
- **3DGS에서의 실용적 의미**: 시점 무관 기본색. 파라미터(`sh0`/`shN`), 학습률, 초기화, PLY 필드명(`f_dc_*`/`f_rest_*`)이 모두 이 구분을 따른다.
