# SH 기저 2D 지도: 등장방형 투영과 축의 의미

**질문** — SH 기저를 2D 지도로 시각화할 때 사용한 투영 방식과 축의 의미는?

**답** — **등장방형(equirectangular)** 지도. 가로축은 방위각 $\varphi$(−180°~180°), 세로축은 극각 $\theta$(0°~180°). 빨강은 양수, 파랑은 음수이며 아래 행(고차 $\ell$)으로 갈수록 무늬의 진동이 잦아진다.

---

## 1. 노트북에서 실제로 어떻게 그렸나

`sh_walkthrough.py`의 해당 셀은 다음 두 조각으로 이루어진다.

```python
def sphere_grid(n_theta=128, n_phi=256):
    theta = (arange(n_theta) + 0.5) * pi / n_theta            # 극각 0 → 180°, 행(row)
    phi   = (arange(n_phi)   + 0.5) * 2*pi / n_phi - pi        # 방위각 −180 → 180°, 열(col)
    th, ph = meshgrid(theta, phi, indexing="ij")
    d = stack([sin(th)cos(ph), sin(th)sin(ph), cos(th)])       # 단위 방향 벡터 [128, 256, 3]
    w = sin(th) * (pi/n_theta) * (2*pi/n_phi)                  # 적분 가중치 sinθ dθ dφ
    return d, w

B = sh_bases(dirs, 3)                                          # [128, 256, 16]

vmax = B.abs().max().item()
for k, (l, m) in enumerate(LM):
    ax = axes[l, m + 3]                                        # 행 = ℓ, 열 = m (가운데가 m=0)
    ax.imshow(B[..., k], cmap="RdBu_r", vmin=-vmax, vmax=vmax,
              extent=[-180, 180, 180, 0])
```

즉 **"구면을 (θ, φ) 격자로 덮고, 그 격자 배열을 그대로 이미지로 찍은 것"**이 지도다. 배열의 행 인덱스가 θ, 열 인덱스가 φ이므로 별도의 투영 계산 없이 `imshow` 한 줄로 등장방형 지도가 된다. 128 × 256(세로:가로 = 1:2) 비율도 θ 범위 180° 대 φ 범위 360°에서 온 것이다.

## 2. 등장방형 투영이란

구면 위의 점을 위경도 $(\theta, \varphi)$로 나타낸 뒤 **그 각도 자체를 직교 좌표 $(x, y) = (\varphi, \theta)$로 쓰는** 가장 단순한 투영이다. 지도학에서는 *plate carrée*(평면 도법), 그래픽스에서는 *lat-long 맵*이라고도 부른다.

- **세계지도**: 경선·위선이 모두 등간격의 직선 격자가 되어 좌표 읽기가 쉽다.
- **환경맵(HDRI)**: 렌더러가 방향 벡터 $\mathbf d$로 텍스처를 조회할 때 $\theta = \arccos d_z$, $\varphi = \operatorname{atan2}(d_y, d_x)$ 두 번의 계산으로 픽셀 좌표가 바로 나온다. 구면 전체가 **직사각형 하나**에 빈틈·중복 없이 담기므로 큐브맵처럼 여섯 면을 다룰 필요가 없고, 2:1 이미지 한 장으로 저장·편집·공유가 쉽다. 노트북 1.3절의 가짜 환경 조명 `env_radiance`와 4절의 시점 의존 색 복원도 같은 `extent`로 그리는데, 이것이 바로 HDRI 형식 그대로다.
- **SH 시각화에 유리한 점**: 3D 구를 그리면 뒷면이 가려지지만, 등장방형 지도는 **구면 전체를 한 번에** 보여 준다. 마디선(값이 0인 곡선)이 격자의 직선과 나란히 놓여서 무늬를 세기도 쉽다(4절).

## 3. 왜 극 근처가 늘어나 보이나 — 넓이 왜곡과 $\sin\theta$ 가중치

구면에서 각도 폭 $d\theta \times d\varphi$인 작은 조각의 **실제 면적**은

$$d\Omega = \sin\theta\, d\theta\, d\varphi$$

인데, 지도에서는 모든 조각이 **같은 크기의 픽셀**이다. 위선 한 바퀴의 실제 둘레는 $2\pi\sin\theta$로 극($\theta = 0°, 180°$)에 가까울수록 0에 수렴하지만, 지도에서는 어느 행이든 가로 256픽셀로 똑같이 펴 놓는다. 따라서

- 극점 **한 점**이 지도의 **맨 위·맨 아래 한 줄 전체**로 늘어나고,
- 극 근처 무늬는 가로로 과장되며(세계지도에서 그린란드가 아프리카만 하게 보이는 것과 같은 현상),
- 적도($\theta = 90°$) 부근만 실제 비율과 거의 같다.

노트북은 이 왜곡을 정확히 알고 있다. `sphere_grid`가 반환하는 가중치 `w = sinθ·dθ·dφ`가 바로 **"이 픽셀이 구면에서 실제로 차지하는 면적"**이다. 그래서

- `w.sum() ≈ 4π` (구면 전체 면적),
- 정규직교성 확인 `gram = einsum("abi,abj,ab->ij", B, B, w)` 가 단위행렬에 가깝고,
- 사영 `project_to_sh`, 구면 평균, MSE 계산이 모두 `w`를 곱한다.

가중치 없이 픽셀을 그냥 평균하면 극 근처 값이 과대평가되어 $Y_\ell^m$끼리의 직교성이 깨지고 DC 계수가 구면 평균과 어긋난다. 즉 **지도 위에서 "면적처럼 보이는 것"과 "구면의 실제 면적"의 차이가 $\sin\theta$이고, 그림에서는 왜곡으로, 수식에서는 가중치로 나타난다.**

## 4. `extent=[-180, 180, 180, 0]` — 축 방향 정하기

matplotlib `imshow`의 `extent`는 **`(left, right, bottom, top)`** 순서다. 따라서

| 항목 | 값 | 뜻 |
|---|---|---|
| left | −180 | 배열 첫 열(`phi[0]`)이 φ = −180° |
| right | +180 | 마지막 열이 φ = +180° |
| bottom | 180 | 배열 **마지막 행**이 θ = 180° (그림 아래) |
| top | 0 | 배열 **첫 행**이 θ = 0° (그림 위) |

`theta`가 0에서 시작해 증가하는 배열이므로 첫 행이 위에 오는 `imshow` 기본 동작(`origin="upper"`)과 일치하고, `bottom=180, top=0`으로 적어 세로축 눈금이 위에서 아래로 0 → 180이 되도록 맞춘 것이다. 만약 `[-180, 180, 0, 180]`으로 썼다면 matplotlib이 y축을 뒤집어 그림이 상하 반전되어 보인다(배열은 같아도 눈금과 그림이 어긋남).

이 규약에서 지도의 위치와 3D 방향의 대응은 다음과 같다.

| 지도 위치 | $(\theta, \varphi)$ | 방향 $\mathbf d = (\sin\theta\cos\varphi, \sin\theta\sin\varphi, \cos\theta)$ |
|---|---|---|
| 맨 윗줄 | θ = 0 | **+z** (북극) |
| 가운데 가로선 | θ = 90° | xy 평면(적도) |
| 맨 아랫줄 | θ = 180° | **−z** (남극) |
| 가로 중앙 | φ = 0 | +x |
| 오른쪽 1/4 지점 | φ = +90° | +y |
| 왼쪽 1/4 지점 | φ = −90° | −y |
| 좌우 양 끝 | φ = ±180° | −x (같은 자오선, 지도에서는 이음새) |

즉 **θ = 0이 위 ⇒ +z가 지도 위쪽**이다. `env_radiance`에서 `sky = 0.5·(z+1)`로 만든 "위쪽 밝은 하늘"이 그림에서도 위에 보이는 이유가 이것이고, 태양 방향 `(0.5, 0.3, 0.8)`은 θ ≈ 36°, φ ≈ 31°이므로 지도 위쪽 중앙에서 약간 오른쪽에 봉우리로 나타난다. 3DGS에서 카메라→Gaussian 방향 $\mathbf d$ 하나는 이 지도의 **점 하나**에 대응하고, SH 평가는 그 점의 색을 읽는 일이다.

## 5. 지도에서 각 기저가 보이는 무늬

실수 SH는 $Y_\ell^m(\theta, \varphi) \propto \{\cos(m\varphi)\ \text{또는}\ \sin(|m|\varphi)\} \times P_\ell^{|m|}(\cos\theta)$ 로 **φ 방향 인자 × θ 방향 인자**의 곱이다. 등장방형 지도에서는 두 축이 분리되므로 무늬가 그대로 읽힌다.

### m = 0 (zonal) — 가로 띠
φ에 무관하므로 각 행이 단색인 **가로 띠**만 생긴다. 마디선(흰 선)은 $P_\ell^0(\cos\theta) = 0$이 되는 위선으로 **ℓ개**.
- $Y_1^0 = c\,z$: 위 빨강, 아래 파랑, 적도가 마디(1개).
- $Y_2^0 = c\,(3z^2 - 1)$: 위·아래 빨강, 가운데 넓은 파란 띠. 마디 θ ≈ 54.7°, 125.3°(2개).
- $Y_3^0 = c\,z(5z^2 - 3)$: 빨-파-빨-파 4개 띠, 마디 3개.

### |m| = ℓ (sectoral) — 세로 줄무늬
$P_\ell^\ell(\cos\theta) \propto \sin^\ell\theta$ 는 극에서만 0이 되어 가로 마디선이 없고, $\cos(\ell\varphi)$ 또는 $\sin(\ell\varphi)$가 φ 한 바퀴에 **2ℓ번** 부호를 바꿔 **세로 줄무늬 2ℓ개**가 나온다(구면에서는 극을 지나는 자오선 대원 ℓ개가 마디).
- $Y_1^{1} = -c\,x$: 가운데(φ = 0, +x) 파랑, 양 끝 빨강. 마디는 φ = ±90°.
- $Y_1^{-1} = -c\,y$: 오른쪽 절반(y > 0) 파랑, 왼쪽 절반 빨강. 마디는 φ = 0, ±180°.
- $Y_2^{2} \propto x^2 - y^2 = \sin^2\theta\cos 2\varphi$: 세로 띠 4개. $Y_3^{3}$: 6개.
- $\sin^\ell\theta$ 때문에 위·아래 가장자리로 갈수록 값이 0에 가까워 **흰색으로 흐려진다**.

### 0 < |m| < ℓ (tesseral) — 바둑판
가로 마디선 **ℓ − |m|개**와 세로 마디선 **2|m|개**가 교차해 바둑판 무늬가 된다.
- $Y_2^{1} \propto xz = \sin\theta\cos\theta\cos\varphi$: 적도(가로 1개) × φ = ±90°(세로 2개) → 4칸.
- $Y_3^{1}$: 가로 2개 × 세로 2개, $Y_3^{2}$: 가로 1개 × 세로 4개.

정리하면 **구면 위 마디 곡선 수는 항상 ℓ개**(위선 ℓ − |m|개 + 자오선 대원 |m|개)이고, ℓ이 커질수록 칸이 잘게 나뉜다 — 이것이 그림 제목의 "아래로 갈수록 진동이 잦아진다(고주파)"의 뜻이다. 같은 (ℓ, |m|)에서 m > 0(cos)과 m < 0(sin)은 **같은 무늬를 φ 방향으로 90°/|m| 만큼 밀어 놓은 것**이라 지도에서는 좌우로 이동한 쌍으로 보인다. 부호는 Condon–Shortley 규약을 따르므로 $Y_1^1 = -c\,x$ 처럼 φ = 0 쪽이 파랑인 경우가 있다는 점만 주의하면 된다.

`axes[l, m + 3]` 배치 덕분에 4 × 7 격자에서 **행을 따라 내려가면 ℓ이, 가로 중앙(m = 0)에서 좌우로 멀어지면 |m|이 커진다**. 왼쪽으로 가면 sin(m < 0), 오른쪽으로 가면 cos(m > 0) 계열이다.

## 6. `RdBu_r`와 대칭 `vmin=-vmax, vmax=vmax`

- `RdBu`는 **발산형(diverging) 컬러맵**으로 한쪽 끝이 빨강, 가운데가 거의 흰색, 반대쪽 끝이 파랑이다. 원래 `RdBu`는 낮은 값이 빨강이므로, **`_r`(reverse)를 붙여 "빨강 = 양수, 파랑 = 음수"**라는 관습적 부호 표시로 맞춘 것이다.
- **대칭 범위가 필수인 이유**: 발산형 컬러맵의 중립색(흰색)은 `(vmin + vmax)/2`에 놓인다. `vmin = -vmax`로 두어야 **0이 정확히 흰색**이 되어 (1) 마디선이 흰 선으로 드러나고, (2) 색만 보고 부호를 판단할 수 있다. 만약 서브플롯마다 자동 범위(`B[...,k].min()~max()`)를 쓰면 흰색이 0이 아닌 값에 놓여 부호를 오독하고, 상수인 $Y_0^0$은 범위가 0이라 그리지도 못한다.
- **모든 16장에 같은 `vmax`**(`B.abs().max()`, ≈ 0.75로 $Y_3^0$의 극값)를 쓰는 이유는 **진폭 비교**를 위해서다. 그래서 $Y_0^0 = 0.282$는 전체가 옅은 빨강 한 색으로 보이고, 고차 기저는 극 근처에서 진한 색까지 도달한다.
- 이어지는 3D 그림도 `RdBu_r(0.5 + 0.5·sign(Y))`로 같은 컬러맵을 부호만 표시하는 데 재사용해, 두 그림의 색 의미를 일치시킨다.

## 7. 한 줄 요약

$(\theta, \varphi)$ 격자에서 계산한 기저값 배열을 `imshow`로 그대로 찍은 것이 **등장방형 지도**다. `extent=(left, right, bottom, top) = (-180, 180, 180, 0)`으로 가로 = φ, 세로 = θ(위가 θ = 0 = +z)를 정했고, 이 투영은 극 근처를 가로로 늘려 보이게 하므로 정량 계산에는 항상 `w = sinθ dθ dφ`를 곱한다. `RdBu_r`에 대칭 범위를 써서 흰색 = 0, 빨강 = +, 파랑 = −로 읽으며, m = 0은 가로 띠, |m| = ℓ은 세로 줄무늬, 그 사이는 바둑판이고 마디 곡선 수는 ℓ개다.
