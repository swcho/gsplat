# SH 계수를 SfM 색으로 초기화하기 — DC 성분은 왜 `(rgb − 0.5) / C0`인가

## 0. 결론 먼저

```python
C0 = 0.28209479177387814          # SH 0차 기저 상수 Y00
sh_coeffs = torch.zeros(N, K, 3)
sh_coeffs[:, 0] = (rgbs - 0.5) / C0    # DC 성분 ← SfM 색
sh_coeffs[:, 1:] = torch.randn(N, K-1, 3) * 0.05   # 고차항은 작게
```

렌더링할 때는 SH를 평가한 뒤 `+0.5`을 다시 더해서 원래 색으로 되돌린다.

```python
colors = torch.clamp_min(spherical_harmonics(...) + 0.5, 0.0)
```

즉 **초기화에서 뺀 0.5를 렌더링에서 다시 더하는 한 쌍**이다. 왜 이런 모양이 되는지를 고교 수학에서 출발해 하나씩 쌓아 보자.

---

## 1. 준비: "방향에 따라 값이 달라지는 함수"란 무엇인가

고등학교에서 다루는 함수는 대개 실수 하나를 받는다. $f(x) = x^2$처럼.

그런데 3D Gaussian Splatting의 색은 **보는 방향**에 따라 달라져야 한다. 금속 표면을 정면에서 보면 어둡고, 비스듬히 보면 반짝이는 것처럼. 이때 입력은 "방향"이다.

방향은 어떻게 표현할까? 원점에서 뻗어나가는 **길이 1인 벡터** $\mathbf{d} = (x, y, z)$, 즉 $x^2 + y^2 + z^2 = 1$을 만족하는 점이다. 이런 점들을 모두 모으면 **단위구(반지름 1인 구)의 표면**이 된다.

> 정리: "방향에 따라 값이 바뀌는 함수" = **구면 위에서 정의된 함수** $f(\mathbf{d})$, 정의역이 구 표면.

gsplat에서 이 방향은 카메라에서 Gaussian을 향하는 벡터를 정규화한 것이다.

$$\mathbf{d} = \frac{\boldsymbol{\mu} - \mathbf{p}_{\text{cam}}}{\lVert \boldsymbol{\mu} - \mathbf{p}_{\text{cam}} \rVert}$$

---

## 2. "기저(basis)"라는 아이디어 — 이미 알고 있는 것

### 2.1 벡터의 경우

평면 위의 아무 벡터 $\mathbf{v}$는 두 기본 벡터의 조합으로 쓸 수 있다.

$$\mathbf{v} = c_1 \mathbf{e}_1 + c_2 \mathbf{e}_2, \qquad \mathbf{e}_1 = (1,0),\ \mathbf{e}_2 = (0,1)$$

$\mathbf{e}_1, \mathbf{e}_2$를 **기저**라 하고, $c_1, c_2$를 **계수**라 한다. 벡터를 다루는 대신 숫자 두 개만 다루면 된다는 게 핵심이다.

### 2.2 함수도 똑같이 할 수 있다

푸리에 급수를 떠올려 보자. 주기함수는 사인·코사인의 합으로 분해된다.

$$f(\theta) = a_0 + a_1\cos\theta + b_1\sin\theta + a_2\cos 2\theta + \cdots$$

여기서 $1, \cos\theta, \sin\theta, \cos 2\theta, \dots$가 **기저 함수**이고 $a_0, a_1, b_1, \dots$가 계수다. 앞쪽 항일수록 "천천히 변하는 큰 흐름", 뒤쪽 항일수록 "빠르게 흔들리는 잔무늬"를 담는다. 특히 **상수항 $a_0$은 함수의 평균값**이다.

### 2.3 구면조화함수 = 구 위의 푸리에 급수

**구면조화함수(Spherical Harmonics, SH)** $Y_{\ell m}(\mathbf{d})$는 정확히 이걸 구 표면에서 하는 것이다. 구 위의 어떤 함수든 이렇게 쓸 수 있다.

$$f(\mathbf{d}) = \sum_{\ell=0}^{\infty} \sum_{m=-\ell}^{\ell} c_{\ell m}\, Y_{\ell m}(\mathbf{d})$$

- $\ell = 0$: 항이 1개. **방향과 무관한 상수** — 평균색.
- $\ell = 1$: 항이 3개. 좌우/위아래로 한 번 부드럽게 변하는 성분.
- $\ell = 2$: 항이 5개. 더 잘게 변하는 성분.
- 차수 $\ell$까지 쓰면 항의 총 개수는 $K = (\ell+1)^2$.

코드의 `SH_DEGREE = 3`이면 $K = 4^2 = 16$개의 계수를 RGB 채널마다 갖는다. 그래서 텐서 모양이 `[N, 16, 3]`이다.

실제 기저 함수 값은 `_eval_sh_bases_fast`에 상수·다항식으로 하드코딩되어 있다.

```python
result[..., 0] = 0.2820947917738781        # ℓ=0: 방향 무관 상수
fTmpA = -0.48860251190292
result[..., 2] = -fTmpA * z                # ℓ=1: z에 비례
result[..., 3] =  fTmpA * x                #      x에 비례
result[..., 1] =  fTmpA * y                #      y에 비례
```

$\ell=0$ 항만 $x, y, z$가 전혀 등장하지 않는다는 점에 주목하자. **방향을 넣지 않으니 방향이 바뀌어도 값이 안 변한다.** 이것이 "DC 성분"이라 불리는 이유다(전기 회로의 직류 DC = 시간에 따라 변하지 않는 성분, 신호처리에서 평균값 성분).

## 3. $Y_{00} = \frac{1}{2\sqrt{\pi}} \approx 0.2821$ 유도하기

이제 핵심. 왜 하필 0.2821이라는 이상한 숫자인가?

### 3.1 정규화 조건

기저는 보통 **정규화**해서 쓴다. 평면 벡터에서 $\mathbf{e}_1 = (1,0)$의 길이가 1인 것과 같다. 함수에서 "길이"에 해당하는 것은 **제곱을 정의역 전체에서 적분한 값**이다.

$$\int_{S^2} \big[Y_{00}(\mathbf{d})\big]^2 \, d\Omega = 1$$

여기서 $\int_{S^2} \cdots d\Omega$는 "구 표면 전체에 걸친 적분"을 뜻한다.

### 3.2 계산

$Y_{00}$는 방향과 무관한 **상수**이므로 $Y_{00} = c$라 두자. 상수를 적분하면 (상수) × (적분 영역의 크기)이다. 구의 표면적은 고교 기하에서 배운 대로

$$S = 4\pi r^2 \;\xrightarrow{\ r=1\ }\; 4\pi$$

따라서

$$\int_{S^2} c^2 \, d\Omega = c^2 \cdot 4\pi = 1$$

$$c^2 = \frac{1}{4\pi} \quad\Longrightarrow\quad c = \frac{1}{\sqrt{4\pi}} = \frac{1}{2\sqrt{\pi}}$$

수치로는

$$Y_{00} = \frac{1}{2\sqrt{\pi}} = \frac{1}{2 \times 1.7724538\cdots} = 0.28209479177387814$$

코드의 `C0`와 정확히 일치한다.

> **한 줄 요약**: $Y_{00}$는 "구 표면적 $4\pi$ 위에서 제곱 적분이 1이 되도록 만든 상수"다. 확률에서 확률밀도함수가 $\int p(x)dx = 1$이 되게 정규화 상수를 붙이는 것과 같은 발상이다(단, 여기선 $\int Y^2 = 1$이라 제곱근이 붙는다).

---

## 4. 왜 $c_0 \cdot Y_{00}$가 "방향 무관한 평균색"인가

두 가지 방향에서 이해할 수 있다.

### 4.1 직관: 방향이 들어갈 자리가 없다

$Y_{00}(\mathbf{d}) = 0.2821$은 $\mathbf{d}$가 무엇이든 같은 값이다. 그러니

$$c_0 \cdot Y_{00} = 0.2821\,c_0$$

도 방향에 무관한 상수. 나머지 $\ell \ge 1$ 항들은 $\mathbf{d}$에 의존하므로 "방향에 따른 변화분"만 담당한다.

### 4.2 엄밀히: 구면 평균과 같다

함수 $f$의 **구면 평균**(모든 방향에서 본 색의 평균)은

$$\bar{f} = \frac{1}{4\pi}\int_{S^2} f(\mathbf{d})\, d\Omega$$

SH의 중요한 성질은 **서로 다른 기저는 직교한다**는 것이다. 특히 $\ell \ge 1$인 모든 $Y_{\ell m}$은 구 전체에서 적분하면 0이 된다(양수 영역과 음수 영역이 정확히 상쇄된다 — $\int_0^{2\pi}\cos\theta\, d\theta = 0$인 것과 같은 이치). 따라서

$$\int_{S^2} f\, d\Omega = c_0 \int_{S^2} Y_{00}\, d\Omega + \underbrace{\sum_{\ell\ge1} c_{\ell m}\int_{S^2} Y_{\ell m}\, d\Omega}_{= \,0} = c_0 \cdot \frac{1}{2\sqrt\pi} \cdot 4\pi$$

$$\bar{f} = \frac{1}{4\pi} \cdot c_0 \cdot \frac{4\pi}{2\sqrt\pi} = \frac{c_0}{2\sqrt\pi} = c_0 \cdot Y_{00}$$

**DC 항의 값 $c_0 Y_{00}$가 곧 전 방향 평균색**이다. 그래서 SfM이 준 "방향 정보 없는 색 하나"를 여기에 넣는 것이 자연스럽다.

### 4.3 그래서 역산

우리가 원하는 것: 평균색이 SfM 색 $\text{rgb}$가 되게 하자.

$$c_0 \cdot Y_{00} = \text{rgb} \quad\Longrightarrow\quad c_0 = \frac{\text{rgb}}{Y_{00}} = \frac{\text{rgb}}{C_0}$$

여기서 0.5 오프셋을 더하면 최종 형태 $c_0 = (\text{rgb} - 0.5)/C_0$가 된다. 다음 절이 그 이유다.

---

## 5. 0.5 오프셋의 의미 — 초기 계수를 0 근처로

### 5.1 오프셋이 없다면

SfM 색은 $[0, 1]$ 범위다. 오프셋 없이 $c_0 = \text{rgb}/C_0$로 두면

$$c_0 \in \left[0,\ \frac{1}{0.2821}\right] = [0,\ 3.545]$$

즉 계수가 항상 **양수이고 평균이 약 1.77**인 치우친 분포가 된다. 반면 고차항($\ell \ge 1$)은 코드에서 보듯 평균 0인 작은 값으로 초기화한다.

```python
sh_coeffs[:, 1:] = torch.randn(N, K-1, 3) * 0.05
```

`torch.randn`은 표준정규분포 $N(0,1)$ 샘플이니, 평균 0, 표준편차 0.05인 작은 값들이다.

### 5.2 오프셋을 넣으면

$\text{rgb} - 0.5 \in [-0.5, 0.5]$이므로

$$c_0 = \frac{\text{rgb} - 0.5}{C_0} \in \left[-\frac{0.5}{0.2821},\ \frac{0.5}{0.2821}\right] = [-1.77,\ 1.77]$$

**평균 0을 중심으로 대칭**인 분포가 된다. 회색($\text{rgb}=0.5$)이면 $c_0 = 0$으로 정확히 0이다.

### 5.3 왜 이게 좋은가

세 가지 이유가 겹쳐 있다.

1. **최적화(경사하강법)의 출발점으로 좋다.** 학습은 $\theta \leftarrow \theta - \eta \frac{\partial L}{\partial \theta}$로 계수를 조금씩 움직인다. 모든 파라미터가 0 근처에서 비슷한 스케일로 시작하면, 같은 learning rate로 고르게 학습된다. DC만 혼자 큰 값(1.77 근처)에서 시작하면 상대적 변화율이 달라 균형이 깨진다.

2. **DC와 고차항의 스케일이 맞는다.** 둘 다 0 중심이므로 "평균색"과 "방향 의존 변화분"이 대등하게 취급된다.

3. **표현 범위가 대칭이다.** 어두운 색($\text{rgb} \to 0$)과 밝은 색($\text{rgb} \to 1$)이 $c_0$의 음/양 양쪽으로 균등하게 배치된다.

### 5.4 반드시 되돌려야 한다

0.5를 뺐으니 렌더링에서는 반드시 더해야 원래 색이 나온다.

```python
colors_view = torch.clamp_min(sh_cuda + 0.5, 0.0)   # +0.5로 복원, 음수는 0으로
```

- `+0.5`: 초기화의 $-0.5$를 정확히 상쇄.
- `clamp_min(..., 0.0)`: 고차항이 크게 흔들려 색이 음수가 되는 것을 막는 안전장치. 색은 음수일 수 없다.

이 두 연산은 항상 짝으로 다녀야 한다. 한쪽만 있으면 전체 화면이 0.5(중간 회색)만큼 어둡거나 밝게 어긋난다.

## 6. 왕복 검산

숫자로 확인해 보자. SfM 색이 순수 빨강 $\text{rgb} = (1.0, 0.0, 0.0)$이라 하자.

**초기화**

$$c_0^{(R)} = \frac{1.0 - 0.5}{0.28209} = 1.7725, \qquad c_0^{(G)} = c_0^{(B)} = \frac{0.0 - 0.5}{0.28209} = -1.7725$$

**렌더링** (고차항을 0으로 두면)

$$\text{R} = c_0^{(R)} \cdot Y_{00} + 0.5 = 1.7725 \times 0.28209 + 0.5 = 0.5 + 0.5 = 1.0 \ \checkmark$$

$$\text{G} = -1.7725 \times 0.28209 + 0.5 = -0.5 + 0.5 = 0.0 \ \checkmark$$

정확히 원래 색으로 돌아온다. 고차항이 있으면 여기에 방향 의존 보정이 살짝 더해져, 카메라 위치에 따라 색이 미묘하게 달라진다. 코드에서도 이 차이를 실제로 출력한다.

```python
print("카메라별 색 차이(시점 의존성) 평균:", (colors_view[0] - colors_view[1]).abs().mean().item())
```

## 7. 한 장 요약

| 요소 | 값·식 | 의미 |
|---|---|---|
| 구면조화함수 | $Y_{\ell m}(\mathbf{d})$ | 구 위 함수의 기저. 푸리에 급수의 구면 버전 |
| $\ell=0$ 항 | $Y_{00} = \frac{1}{2\sqrt{\pi}} \approx 0.2821$ | 방향 무관 상수. 구 표면적 $4\pi$에서 $\int Y^2=1$로 정규화 |
| DC의 뜻 | $c_0 Y_{00} = \bar{f}$ | 모든 방향 평균색 ($\ell\ge1$은 적분하면 0) |
| 초기화 | $c_0 = (\text{rgb} - 0.5)/C_0$ | 평균색 = SfM 색이 되도록 역산 + 0 중심화 |
| $-0.5$ | $c_0 \in [-1.77, 1.77]$ | 계수를 0 근처 대칭 범위로 → 학습 안정 |
| 복원 | `clamp_min(sh + 0.5, 0)` | 오프셋 되돌리고 음수 색 차단 |
| 고차항 초기값 | `randn * 0.05` | 평균 0, 작은 시점 의존성 |
